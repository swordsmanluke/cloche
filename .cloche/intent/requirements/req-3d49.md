Bot SSH keys generated by `cloche init` live under `~/.ssh/`, not inside the project tree (`.cloche/ssh/`) or under `~/.config/cloche/ssh/`.

**Why:** `~/.ssh/` is the conventional, discoverable location for SSH private keys with appropriate permissions and tooling support; keeping the key inside the project tree risks accidental commit despite gitignore, and a cloche-specific config directory is safer but fragments SSH key management across two places.
