If `release-tag` succeeds but `release-publish` fails partway (e.g. a network error), the local tag and commits are left in place — recover by hand with `git push origin main`, `git push origin v<VERSION>`, and `gh release create`, rather than re-running the whole release workflow.

**Why:** The tag and commit are already valid local state; retrying the full workflow risks re-tagging or duplicating work instead of just finishing the publish step.
