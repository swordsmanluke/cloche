Agent-step CLOCHE_RESULT markers are framed with a per-step random nonce (CLOCHE_RESULT:{{ $result_nonce }}:<name>), not the bare CLOCHE_RESULT:<name> form.

**Why:** A free-form coding agent's own transcript can otherwise reproduce the literal string CLOCHE_RESULT:success while grepping code, editing test fixtures, or discussing the result protocol itself. Framing the marker with a random nonce means only a line the agent deliberately copied from its own instructions counts, so quoted or incidental mentions elsewhere in the transcript don't get misread as the step's result. Host workflow script steps get the same treatment via a CLOCHE_RESULT_NONCE env var for scripts that shell out to other commands. Poll and skip steps are author-controlled and keep the unnonced bare form.
