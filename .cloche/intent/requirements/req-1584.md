Host-workflow script and poll steps' working directory defaults to the main git worktree, but this is a default, not a guaranteed invariant: `MainWorktreeDir()` falls back to the project directory on any error (not a git repository, `git` unavailable, or `git worktree list` failing). Scripts that care which tree they're operating in should resolve it at runtime rather than assume.

**Why:** docs/workflows.md previously stated the main-worktree cwd as an absolute rule; that overstated the guarantee the executor actually provides, so a script relying on it unconditionally can silently run against the wrong tree when the fallback kicks in.
