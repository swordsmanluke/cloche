A bot SSH key is only ever generated when the user explicitly opts in (choosing "generate" at the `cloche init` interactive prompt, or passing `--ssh-key`). `cloche init` never generates a push key silently, including under `--non-interactive`.

**Why:** Generating and registering an SSH key is a security-relevant action with a manual GitHub registration step; it should never happen as a surprise side effect of running init.
