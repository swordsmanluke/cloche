`cloche init` is safe to run on any project, including one already set up with Cloche — it never overwrites existing `.cloche/` files.

**Why:** Lets a user clone a repo that's already been set up with Cloche and get their own instance working (registering with the daemon, refreshing config.toml) without clobbering the checked-in workflow files.
