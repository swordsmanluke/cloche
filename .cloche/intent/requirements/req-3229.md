Neither the `changelog` nor the `release` host workflow bumps `internal/version/VERSION` itself. If a release should land on a clean version number, bump manually with `bumpver minor|major` and commit before running `changelog`.

**Why:** Per-task build bumps already accumulate the build number automatically; separating the release workflows from bumping keeps the maintainer in control of when a clean number is warranted.
