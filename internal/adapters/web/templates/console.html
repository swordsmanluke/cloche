Keyboard shortcuts

j / k
Move selection down / up
Tab / Shift+Tab
Switch project
Enter
Open the selected task
Esc
Return to the stack, or close an open view/drawer
a
Open the activity stream
l
Open the project ledger
[ / ]
Scope the log to the previous / next step, wrapping across child-run steps
Shift+[ / Shift+]
Switch to the previous / next attempt
g / G
Scroll the log to the top / bottom
f
Toggle following the live log to its newest line
r
Release your claim on the open needs-you task (when available); otherwise cycles the repo sub-tabs (when the project has more than one repository)
Shift+R
Jump straight to the "all repos" sub-tab (when the project has more than one repository)
x
Close the open needs-you task in the tracker (when available)
w
Open the Workflows view
i
Open the Requirements view
c
Open the Containers view, or toggle the needs-you compare view / single-attempt log when one is open
d
Toggle compact / comfortable density
?
Toggle this help

Shortcuts are single keys. Cmd/Ctrl chords (e.g. Cmd+C, Ctrl+C) are left to the browser.
