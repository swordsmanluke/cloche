# The Cloche Quickstart Guide

These pages will teach you the basics you need to understand how to use Cloche.
Once you've finished these, you can dip into the main documentation site as needed for advanced topics.

1. [Cloche](1-what-cloche-gives-you.md): controlling your agentic workflows
2. [Steps](2-steps.md): the basic building block
3. [Workflows](3-workflows.md): steps plus wiring, on the host or in a container
4. [The DSL](4-the-dsl.md): a complete workflow, line by line
5. [Tasks](5-tasks.md): `list-tasks` and `main`
6. [Let agents build them](6-let-agents-build-them.md): tips for working with your coding agent
7. [Patterns](7-patterns.md): five shapes that cover most workflows

To install Cloche, see the [installation guide](http://cloche.perfectlunacy.com/getting-started/installation/).
